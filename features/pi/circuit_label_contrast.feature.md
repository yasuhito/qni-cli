# Feature: qni ツールの回路図を端末の背景に対して読める色で描く

量子回路を説明する共同研究者として
明るい端末でも暗い端末でも
量子ビットのラベルと配線を読みたい。

色は Pi の文字色を基本にする。端末の背景とのコントラスト比が 2 未満のときと、Pi の文字色が不明なときは、端末の前景色を使う。

## Scenario: 明るい端末では量子ビットラベルを Pi の文字色で描く

- Given 端末の前景色 "#100f0d"、背景色 "#fffcf0"、Pi の文字色 "#100f0d" で qni ツール拡張を登録する
- When qni ツールで H ゲートを追加して回路を表示する
- Then 回路図の量子ビットラベルは "#100f0d" で描かれる

## Scenario: 暗い端末では量子ビットラベルを Pi の文字色で描く
