# Feature: 逆三角関数を使う状態準備の記号採点

正規化された振幅の全定義域で、ゼロ入力からの状態を全体位相も含めて証明する。回転状態は実数角による全円の再パラメータ化、任意状態は閉区間の振幅と独立した実数位相を使う。

## Scenario: 一般化した二課題の標準解

- When 逆三角関数課題の標準解を採点する
- Then 逆三角関数課題の二つの結果は証明済みになる

## Scenario: 厳密比較では全体位相も必要

- When 逆三角関数課題へ全体位相だけが異なる解を提出する
- Then 逆三角関数課題の二つの結果は未証明になる

## Scenario: 固定値では全定義域を証明できない

- When 逆三角関数課題へ固定値の解を提出する
- Then 逆三角関数課題の二つの結果は未証明になる

## Scenario: 閉区間の振幅宣言を保存する

- When 逆三角関数課題の標準解を採点する
- Then 任意状態の記号仮定は alpha の unit-interval と独立した theta の real を含む

## Scenario: 閉区間の端点でも定義できる平方根

- When 任意状態の記号採点へ正規化振幅の平方根を含む解を提出する
- Then 記号採点の結果は証明済みになる

## Scenario: 未定義の平方根は相殺しても使用できない

- When 任意状態の記号採点へ未定義の平方根を相殺した解を提出する
- Then 逆三角関数課題の結果は未証明になる

## Scenario: 主値の象限を取り違えた任意状態

- When 任意状態の記号採点へ asin に置換した解を提出する
- Then 逆三角関数課題の結果は未証明になる
