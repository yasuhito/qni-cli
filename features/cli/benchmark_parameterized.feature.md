# Feature: 可変長入力を持つ中立JSON提出物の採点

制限付きの式・配列・分岐・有限ループを各採点入力で展開する。有限標本であり全定義域の証明ではない。FourBitstrings は固定値を維持する。

## Scenario: 十二課題の標準解を複数入力で採点する

- When 可変長課題の標準解を一括採点する
- Then 可変長課題の十二件は全て合格する

## Scenario: 状態準備では全体位相を許容する

- When 可変長 GHZ 課題へ全体位相だけ異なる解を提出する
- Then 可変長課題の採点結果は passed になる

## Scenario: 固定値解は別の長さで不合格になる

- When 可変長 GHZ 課題へ固定幅の解を提出する
- Then 可変長課題の採点結果は failed になる

## Scenario: 入れ子の空ループも資源上限の対象になる

- When 可変長 GHZ 課題へ過大な空ループを提出する
- Then 可変長課題の採点結果は failed になる

## Scenario: 幅の追加は状態準備でも認めない

- When 可変長 GHZ 課題へ余分な量子ビットを提出する
- Then 可変長課題の採点結果は failed になる

## Scenario: 非公開入力は結果に露出しない

- When 可変長課題の標準解を一括採点する
- Then 可変長課題の結果には入力値を含めずケース識別子を保存する
