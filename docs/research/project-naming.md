# プロジェクト命名メモ

## 現状

現在の名前は `Qni` / `qni-cli` だが、`qni-cli` は量子回路を決定論的に実行・検証するCLIを指す名前として強い。共同研究者としてのAI、研究試行ログ、比較、レポートまで含むプロジェクト全体を表すには、CLI寄りすぎる可能性がある。

## 問題意識

このプロジェクト全体の目的は、AIが量子回路を組み立て、qni-cli などの決定論的なツールを使いながら、人間の共同研究者として研究を進められるようにすること。CLIは共同研究者が使う道具の一部であり、プロジェクト全体そのものではない。

## 候補

- Qni CoResearcher
- Qni Co-Researcher
- Qni Research Collaborator

## 未決定事項

- `qni` コマンド名は維持するか。
- npm package 名は変えるか。
- GitHub repository 名は変えるか。
- 研究ログやレポートで表示するプロジェクト名だけを先に変えるか。

## 当面の方針

研究試行ログのMVPを先に進める。プロジェクト名の変更は、CLIを超えた共同研究者機能の輪郭がもう少し固まってから検討する。
