# AIエージェント評価は qni コマンド提出物を採点する

量子回路AIエージェント評価では、評価ランナーがAIモデルを直接呼び出さず、AIまたは人間が作成した `.qni` 提出物を受け取って採点する。提出物は1行1コマンドの完全な `qni ...` コマンド列とし、`circuit.json` の直接提出や任意 shell script は採点対象にしない。

この判断により、人間、Pi、Codex、Claude などの生成元を同じ提出形式で比較できる。採点の信頼性は課題ファイルの固定された検証条件と qni-cli の決定論的な実行に持たせ、AI自身の説明や自己検証方針は後続の研究ログや上位評価で扱う。
