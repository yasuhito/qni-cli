# 研究試行IDはUTC秒精度タイムスタンプとslugで作る

`qni research record` の初期機能では、研究試行IDと研究試行ディレクトリ名を一致させる。形式は UTC の秒精度タイムスタンプと `--slug` を組み合わせた次の形にする。

```text
research/runs/2026-06-30T123456Z-smoke-claude/
```

この判断により、同じ日に複数回実行しても衝突しにくく、時系列で並べやすく、ファイルパスとして扱いやすい識別子になる。`metadata.json` の `id` には、ディレクトリ名と同じ `2026-06-30T123456Z-smoke-claude` を保存する。
