# 参照回路とのユニタリ等価性で採点する

## 問題

Quantum Katas の QFT 移植には、初期状態一つの出力ではなく変換全体の検証が必要になる。既存の `run` と独立した採点ケースを全基底に展開するだけでは、ケースごとの位相補正によって誤った対角位相を許してしまう。

## 利用方法と構造

`checks.items` に `type: unitary` と `reference_circuit: {qubits, cols, variables?}` を指定する。参照回路は既存の回路ファイルと同じ列形式で埋め込む。`checks.tolerance` は有限・非負とし、`up_to_global_phase` は真偽値だけを受け付ける。

課題読込で既存の回路構造検証を再利用し、採点器は提出コマンド実行後の回路を読み取る。専用モジュールの `compareReferenceCircuit(actual, reference, tolerance, upToGlobalPhase)` は全基底の数値シミュレーション、行列比較、最大16件の診断を隠す。CLI と JSON は既存の検証項目の結果経路を使う。

量子ビット数は完全一致が必要で、不一致は理由付きの不合格にする。補助量子ビットの消去や部分系比較はしない。全基底をメモリ上の初期状態に設定し、提出回路の保存済み初期状態は無視する。参照回路の `initial_state` は指定禁止。測定・古典条件付き操作などユニタリでない操作はエラーにする。ファイルを書き換えない。

## 位相と許容誤差

[ADR 0026](0026-opt-in-to-global-phase-insensitive-state-checks.md) の明示指定方針を `unitary` にも適用する。省略・`false` は厳密比較、`true` は行列全体に共通する一つの単位位相だけを許容する。期待行列の最大振幅成分（同値なら入力基底順・出力基底順で最初）から位相を決め、期待行列全体に掛ける。基準の実測振幅がゼロなら位相1とする。

実部・虚部の差をそれぞれ `tolerance` 以下か比較する。絶対値だけの比較や正規化はしない。列ごとの独立な位相補正は禁止する。QFT 移植時にも課題名で位相方針を推測せず、上流の厳密検証を必要とする課題では既定を維持する。

## 設計比較

埋め込み回路を受け取る専用モジュールを採用する。参照コマンドを一時ディレクトリで実行する案は、参照側にもコマンド権限とファイル管理を増やすため採用しない。数値行列だけを受け取る純粋比較器の案からは、単一位相と決定的な診断順序を取り入れるが、行列生成まで隠す小さい入口を優先する。独立ケースへの展開は位相の意味を崩すため不採用。

全基底検証は指数的な時間・空間を要する。小規模な固定サイズの kata を対象に上限8量子ビットとし、どちらかの回路がこの上限を超える場合はエラーにする（量子ビット数の不一致判定より先に検証する）。既存の `run` の規則や51課題の採点条件は変更しない。[ADR 0019](0019-research-report-does-not-regrade.md) に従い過去の結果も再採点しない。

## 実装順序

機能仕様を先に追加し、参照回路の読込、専用比較モジュール、既存採点経路への接続、node:test と CLI の検証を順に実装する。QFT の12課題自体の移植は別PRで行う。
