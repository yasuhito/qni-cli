# 固定幅の連続引数課題は記号証明を主採点にする

## 背景と判断

高宮さん承認の Stage PA。量子ビット数が固定で角度・連続引数だけが変わる課題では、有限個の数値一致は一般解の検証にならない。**宣言した定義域の全引数について、参照との等価性を記号的に証明することを主判定とする。** 数値標本で証明を代用したり、証明失敗を数値採点で救済したりしない。

可変 N、整数、ビット列・配列を扱う課題は別経路とする。後続 PR の approach a（複数値による数値採点）で扱い、本 PR は可変長生成器、条件分岐、測定、配列引数を導入しない。N を固定しただけの回路を「全 N の証明」と呼ばない。

## 利用と構造

呼び出し側は従来と同じ `gradeBenchmarkTask` / `gradeBenchmarkSuite`、CLI は `qni benchmark run task.md answer.json` を使う。課題の `symbolic` が採点方式を明示し、数値 `checks` / `grading_cases` と併記できない。証明の入口 `proveSymbolicSubmission` は、構文検証、正確な行列構築、定義域の検査、時間・資源制限と結果分類を内部に持つ。呼び出し側は数式処理の各段階を調整しない。

`neutral-symbolic-circuit-json-v1` は独立した提出プロトコルとする。引数宣言、固定幅、ゲート操作、制限された式の構文木を持つ中立 JSON を直接解釈する。式文字列や任意コードを実行せず、`eval`、`sympify`、`parse_expr` は使わない。有理数は整数文字列の分子・正の分母で表す。π、加算、乗算、負号、sin/cos、sqrt、asin/acos/atan のみを許可する。sqrt は非負の主値、逆三角関数は実数主値。除算は定数有理数だけで、分母の零点や極を持つ式は作れない。

引数仮定は課題が所有する。PA の4課題は独立した実数 α∈ℝ とし、提出物に同じ宣言を要求する。複素数・未宣言引数・定義域の縮小を許可しない。sqrt と asin/acos は構文木の保守的な区間計算によって全域で定義できることを確認する。未確認の定義域を仮定して証明しない。一般の正規化制約付き振幅は後続拡張で、現段階では角度による正規化を使う。

状態準備は固定幅の |0…0> からの状態を、変換課題はユニタリ行列全体を比較する。q0 は最上位ビット。実数角とユニタリゲートだけを受け付けるため、状態のノルム1・変換のユニタリ性は全引数で保証される。独立した任意の入力振幅は線形性によりユニタリ全体の一致から扱える。

## 証明と結果

既存の SymPy **1.14.0** 環境を再利用する。浮動小数点係数、数値代入、許容誤差、`equals()` による推定を使わない。正確な有理数・根号・三角関数・複素指数関数で行列を作り、`trigsimp` / `simplify` による残差がすべて記号的に厳密な零になった場合だけ `proved` とする。一般恒等式判定の完全性は主張しない。等しい式でも簡約が成功しない場合がある。SymPy の正確な簡約を信頼する記号証明であり、独立した検査器用の証明書を生成する形式証明ではない。区間計算で相関を失う `sqrt(alpha*alpha)` なども定義域未確認として不合格になる。

- `proved` → `passed`、終了コード0。
- `unproven` → **`failed`、終了コード1**。これは誤りの証明ではなく、許可された証明手順・資源内で全域等価性が証明されなかったことを意味する。非零残差、定義域を確認できない式、非対応構文、不正JSON、幅・引数・ゲート権限違反、時間切れ、資源上限を含む。数値で一致しても不合格。
- 補助実行環境の欠落・故障は `error`、終了コード3。環境故障を誤答の証明と扱わない。

構造化出力は `submissionProtocol`、`symbolicAssumptions`（引数・実数定義域・幅・比較対象・正規化・位相方針）、検証項目の `proof: {verdict, reason}` を持つ。

位相厳密が既定方針。課題で `up_to_global_phase: true` の場合だけ、状態は密度行列、ユニタリは U V† がスカラー恒等行列であることを証明する。全行列に共通する単位位相だけを許容し、入力列ごとの位相は許容しない。共通位相は引数に依存してよい。零振幅の成分で割らず、特異な位相基準を選ばない。参照・提出がともに正規化済みなので比例の絶対値は必ず1になる。

## 隔離と資源

子プロセスに検証済み文法のデータだけを渡す。Python は `-I -B` で起動し、ユーザー環境・モジュールパスを引き継がない。実行中のパッケージ取得やネットワークへのフォールバックはしない。採点器の補助プログラム・Python環境・依存は信頼できる管理下に置く。提出は `O_NONBLOCK` で開いた同一ファイル記述子で通常ファイルを確認し、64 KiB+1を上限に読む。FIFO・デバイス・読み込み中のサイズ変更による上限迂回を防ぐ。信頼する補助プログラムだけが実行され、提出物はファイルパス・関数名・コードを指定できない。これは任意 Python を受け付けるサンドボックスではなく、データ言語の解釈と資源隔離である。

親の壁時計15秒で SIGKILL、補助側 CPU12秒・アドレス空間768 MiB。幅1〜4、操作64、引数8、式深さ16、式節点2048、整数32桁、提出64 KiB、応答64 KiB。時間境界付近の合否は環境性能に依存するが、証明未成立を合格にしない。版固定済み環境は `scripts/setup_symbolic_python.sh` で事前準備する。

## 既存 ADR と過去結果との境界

- ADR 0002 の `.qni` コマンド採点は既存課題に維持する。記号課題に限り中立 JSON を直接採点する明示的な例外。
- ADR 0022 の `blind-neutral-circuit-json-v1` と `qni-command-output-v0` は変更しない。新形式は `.qni` へ変換せず、独立プロトコルで保存・比較する。記号課題を既存 `research solve` の変換経路へ送ると明示エラーとする。
- ADR 0027 の具体的 π 式文字列を変数へ暗黙拡張しない。ゲート名ごとの権限も維持し、CRx の許可から Rx の制御数や MCX の許可を導かない。
- ADR 0026/0028 の位相方針とユニタリ全体比較を引き継ぐ。
- ADR 0019 に従い保存済み結果を再採点・移行しない。旧63課題・標準解は履歴互換用にそのまま保持し、一般化した4課題を `benchmarks/quantum-katas-symbolic` に置く。固定幅・連続引数の新しい評価にはこちらを主スイートとして案内する。旧数値63件と記号4件の合計67ファイルは、67個の異なる上流問題を意味しない。

## 設計候補の比較

SymPy 補助方式を基案とする。依存なしの独自円分体・Laurent 多項式方式も検討したが、固定 π 角の円分体だけでは連続引数・根号・逆三角関数の要件を満たさず、完全な独自代数の保守が必要になるため採用しない。区間による定義域検証と有限な構文木は独自方式の長所として取り入れた。描画器の出力比較は表示正規形を証明と混同するため不採用。複数の数値代入は全引数の証明にならず、可変 N/配列の後続経路に限定する。

新しい重い依存は追加しない。既存 SymPy で正確な係数と保守的な証明を小さい入口に隠す代わりに、証明器の不完全性と Python 起動費用を受け入れる。一般の定義域・正規化制約、研究筆記試験への新プロトコル統合、より強い恒等式手順は後続で扱い、既存プロトコルの意味を変えない。
