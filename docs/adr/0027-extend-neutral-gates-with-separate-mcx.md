# 中立ゲート語彙を拡張し、MCX の許可を固定制御ゲートから分離する

Quantum Katas の回転・制御付き状態準備に必要な `Rx/Ry/Rz`、`CH/CRx/CRy/CRz`、`MCX` を `blind-neutral-circuit-json-v1` に追加する。`MCX(controls, target)` は1個以上の可変長制御配列を取る独立語彙とし、`X`、`CNOT`、`Toffoli` の引数数や許可範囲を拡張する案は、既存課題の制約を暗黙に緩めるため採用しない。

1制御・2制御も MCX として表せるが、固定制御ゲートとの相互許可は行わない。3制御以上に限定する案より、制御数によって解答の名前を切り替えずに済む一般の多重制御操作を優先する。制御付き回転は CNOT/CZ/CH と同じ短い接頭辞を使い、対称性のため CRz も含める。

角度は既存の位相ゲートと同じ有限な π 式文字列を使い、数値ラジアンや変数の導入は別の判断に分離する。既存の提出物・署名の意味と、[ADR 0022](0022-separate-neutral-json-and-legacy-qni-protocols.md) の JSON から既存採点器へ渡す境界は維持する。追加語彙は課題の `available_gates` で明示的に許可するため、プロトコル識別子と保存済み研究試行は変更せず、再採点もしない。

Refs #441。署名と提出例の正本は [中立回路 JSON のゲート語彙](../neutral-circuit-json.md)。
