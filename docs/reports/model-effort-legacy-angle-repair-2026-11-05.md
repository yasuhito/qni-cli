## 保存済み回路の再現と修正

修正前の実際の CLI では、`Ry(2*2π)` を持つ保存済み `circuit.json` に対して `qni run` が `invalid angle: 2*2π`、終了コード1になった。これは旧版の `2*2pi` が保存する表記である。

原因は `AngleParser.product` が、暗黙の π 積を許す条件として直前の数値因子ではなく、途中までの積全体の構文木を見ていたことだった。乗算の直後の符号付き数値因子を記録し、除算の後にはその資格を取り消すように変えた。`1/2pi`、`2/3π`、`2*1/2pi`、`1/-2pi` の拒否は維持する。関数、定義域、変数、資源上限、記号証明の仕組みを広げていない。

次を公開 API と実際の CLI の回帰にした。

- `2*2pi` と保存表記の `2*2π`
- `2*3π/4`
- `-2*3pi_4`
- `0.5*2pi`
- `1.5*-2pi`
- 元の入力は読めても保存表記が読めなかった `2*2*pi_3` と `2*2π/3`

機能仕様とテストを先に追加し、CLI の7シナリオ中6失敗を確認した。修正後は7シナリオ・15ステップと重点131 API テストが成功し、最初の保存済み回路も終了コード0になった。

基点 `5aed97a` の旧 `angle_expression.ts` を Git オブジェクトから読み、37種類について原入力・保存表記の読み込み、表示の完全一致、数値の一致を比較した。修正前は29種類に不一致があり、修正後はすべて一致した。数値比較の相対許容差は `1e-13`。旧参照コードは読み取り専用の信頼したプロジェクトコードで、ログをコードとして実行していない。

実装コミットの最新の全体チェックとコミットフックは1,573シナリオ・4,234ステップで成功した。
