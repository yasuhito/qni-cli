# 回路レンダリング D02 検証報告

## 対象

D01（https://github.com/yasuhito/qni-cli/pull/431）を含む `main` の `3dcdcb6` から、次の3点を独立して検証した。

- 高桁の量子ビットラベルと SVG ワイヤの重なり
- 長い SVG 測定名と計測器の重なり
- キャプション文字列、位置、文字サイズによって変わる PNG の余白

SVG は `qni export --svg`、PNG は `qni export --png` の実経路で生成した。確認環境は TeX Live 2026 の pdfTeX 1.40.29、Poppler 26.08.0、Pillow 12.1.1 である。PNG の正確な画素数はこれらの版によって変わりうるため、回帰テストでは固定寸法ではなく、描画後のインク端から余白を測っている。

## 再現結果

| 症状       | 起点となる入力                                | 境界と反証例                                                                                   | 変更前の見え方                                                             |
| ---------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 高桁ラベル | 1001量子ビット回路の `q1000`                  | `q99` はワイヤまで9px、`q100` と `q999` は1px、`q1000` は-6px。通常の1〜8量子ビットでは17px    | 固定のワイヤ開始位置48pxをラベルが6px越え、文字へワイヤが入る              |
| 長い測定名 | `Measure>very_long_measurement_register_name` | 1文字名では重なりなし。4、8、12文字名ではそれぞれ10、23、36px重なる                            | 列幅は広がるので画像端の切り抜けは隠れるが、中央揃え文字列が計測器側へ戻る |
| PNG 余白   | `gyp jq`、下、24pt、および `gyp`、上、8pt     | D01 の通常回路はおおむね16px。キャプションの字面、ディセンダ、位置、サイズを変えると差が広がる | 下24ptは L/T/R/B = 16/17/15/10px、上8ptは16/26/15/17px                     |

切り分けでは、固定ラベル幅、測定名の中央揃え、TeX の行ボックスと実際の字面の差を上位仮説とした。短いラベル・測定名が成功する反証例と、キャプションだけで上下余白が変わる結果から、それぞれの原因を分離した。Poppler の丸めは1px程度の左右差は説明できるが、キャプションで生じた6〜10pxの差は説明しない。

## 修正

- SVG のワイヤ開始位置を、回路内で最も桁数の多い量子ビットラベルから算出する。通常の1〜8量子ビットでは D01 の48pxを維持する。
- 測定名を計測器の右側から始まる等幅文字列にし、文字数に応じた右側の列幅を確保する。列の左右幅を分け、長い名前のために計測器まで不必要に右へ移動しない。
- キャプション付き PNG だけを、`pdftocairo` が描いたアルファ付き画像の実インク端で切り出して16pxを足す。不透過画像はその後でキャプションなしと同じ白背景へ合成する。キャプションなし PNG の自然な縦横比と D01 の寸法経路は変更しない。

## 決定論的な回帰検証

### 固定ケース

- `q1000` の実描画ラベルとワイヤ間隔が8px以上
- 長い測定名の実描画文字列と計測器間隔が4px以上、かつ右端余白が16px以上
- 上8pt、下24pt、ディセンダ、アセンダ、長いキャプションの四辺が15〜17px
- 透過 PNG と不透過 PNG の両方

SVG の文字境界は実際の SVG を `resvg` で描いて検査し、PNG は `pdflatex` と `pdftocairo` の実出力を検査する。

### seed 固定生成ケース

seed `0xD02` から次を生成する。

- SVG: 1〜8量子ビットと100〜1200量子ビット、4〜36文字の測定名を8件。ラベルとワイヤ、測定名と計測器、測定名と表示領域の不変条件を検査する。
- PNG: 1〜8量子ビット、上/下、8〜28pt、明/暗テーマのキャプションを8件。四辺のインク余白が15〜17pxであることを検査する。

## 変更前後の成果物と Lavish 目視レビュー

2026-09-15 に Lavish セッション `6e6e3b4693c3c276` で、固定敵対ケースの変更前後と seed `0xD02` の SVG 6件・PNG 6件を並べて確認した。レビュー画面では次を合格条件として明示した。

- `q1000` とワイヤの間に空きがある
- 長い測定名が計測器の右から始まり、計測器と画像端に重ならない
- キャプションと回路が切れず、四辺の余白が均等に見える
- seed 固定ケースに新しい重なりや不自然な切り抜けがない

人間の判定は **PASS** で、返却された記録は「fixed and seed-fixed sets have no visible overlap, clipping, or unbalanced margins」だった。固定 PNG の変更後実測は両ケースとも L/T/R/B = 16/16/16/16px、seed 固定 PNG 6件も全辺16pxだった。
